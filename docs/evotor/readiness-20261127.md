## Исправления при проверке

- Тест конкуренции кассира с онлайн-резервированием получил полноценную настройку терминала, сумму наличных и ключ идемпотентности. Теперь проигравший запрос обязан завершиться именно ошибкой вместимости. Ошибка настройки больше не даёт ложный успешный результат теста.
- Новый статус оплаты ограничен кассиром, источником CASHIER и текущей областью доступа; ответы не кешируются. Production-адаптер использует действующую политику ролей: общий доступ только у OWNER. Создан генератор маршрута для точной рабочей сборки.
- Некорректный JSON/хеш в конфигурации терминалов возвращает NOT_CONFIGURED / 503 без раскрытия конфигурации.
- Добавлено объединение полной production Prisma-схемы с таблицей очереди. Сохраняется исходная схема целиком, добавляется только отношение Order.evotorCheckout и модель очереди. Неизвестная контрольная сумма исходной схемы отклоняется.
