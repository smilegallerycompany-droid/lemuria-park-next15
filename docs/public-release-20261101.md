## Сохранение существующего production

Обнаружено расхождение исходников и production: GitHub-снимок не содержит части октябрьских изменений (наблюдатель, PDF и финансовые функции). Поэтому полный build этой ветки не продвигался в production.

Выпущен ограниченный слой поверх **точного рабочего digest**:

`sha256:864ec15ed7cff7a28df1a45a9f6e1c404bad992fb58e234c1fc235280bb864f1`.

Изменены публичные booking/map-модули в браузерном и серверном вариантах, общий JS entry с ограничением запуска Метрики по домену/пути, ссылки в Next.js manifests и имена изменённых статических JS-файлов. Новые имена исключают использование старых immutable JS из браузерного кэша. В образ добавлен публичный манифест релиза. Бизнес-логика API, Prisma, схема, зависимости, кассовые и платёжные сервисы взяты из рабочего образа.
