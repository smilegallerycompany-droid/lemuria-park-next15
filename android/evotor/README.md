# Лемурия Парк · касса

Для сборки нужны Android SDK 35, Build Tools 35.0.0, JDK 17 или 21 и Gradle 8.9.

```bash
gradle :app:testDebugUnitTest :app:assembleDebug -PevotorAppUuid=UUID_ИЗ_КАБИНЕТА_ЭВОТОРА
```

Пакет приложения — `ru.lemuriapark.cashier`. Пробную сборку загружают во вкладке «APK» карточки приложения. Приложение подключается к тестовому API CRM с указанным в настройках токеном. Сопоставьте позиции CRM с существующими карточками на Эвоторе и проверьте наличные, банковский терминал и восстановление после перезапуска.

Официальная инструкция по тестовой установке: https://developer.evotor.ru/docs/doc_app_installation.html

Версия исходников кандидата: 0.1.3 (versionCode 4). Это ещё не готовое обновление для рабочей кассы: ограничения и порядок проверки описаны в [checkout-rollout.md](../../docs/evotor/checkout-rollout.md).

В настройках подключения нужно выбрать установленное банковское приложение (например, Сбер). Базовая «безналичная оплата» Эвотора не подходит для автоматического запуска терминала. Для наличных CRM передаёт сумму полученных денег и сдачу. Оплата отмечается в CRM только после сверки фискального чека. Не удаляйте данные приложения при незавершённой операции: журнал нужен для предотвращения повторной оплаты.

Приём заказов выполняет отдельная служба с постоянным уведомлением. После включения приёма окно приложения можно свернуть; настройка сохраняется. Кнопка «Приостановить приём» останавливает получение новых заданий, но не бросает уже начатый расчёт и передачу его результата. После перезагрузки или обновления служба восстанавливает ранее включённый приём либо незавершённый расчёт. Принудительная остановка приложения и ограничения энергосбережения требуют отдельной проверки на кассе.

16 JUnit-тестов проверяют расчёт, журнал и двигатель приёма с имитацией устройства. Работа службы после перезагрузки, при выключенном экране и запуск банка из фона на конкретной прошивке Эвотора ещё должны пройти аппаратную проверку.

## Подпись обновления установленной кассы

`assembleRelease` требует `EVOTOR_KEYSTORE`, `EVOTOR_STORE_PASSWORD`, `EVOTOR_KEY_ALIAS`, `EVOTOR_KEY_PASSWORD`. Для PKCS12 дополнительно `EVOTOR_KEYSTORE_TYPE=PKCS12`. Пароли не передавать аргументами Gradle и не коммитить. Проверяется SHA-256 сертификата установленной 0.1.2: `e697bff5efb8c5227b78f7fe6637a97a940550623535c6df19ddcec8092b1d10`. Другой сертификат блокирует сборку. Это не восстанавливает утраченный ключ. Не удалять рабочее приложение ради debug-APK.

## Установка рядом с текущей кассой

Отдельное тестовое приложение в кабинете Эвотора использует пакет
`ru.lemuriapark.cashier.replacement` и собственный UUID. Команда сборки,
после загрузки ключа из Yandex Lockbox в защищённый временный каталог:

```bash
gradle --no-daemon :app:testReleaseUnitTest :app:assembleRelease \
  -PevotorReplacement=true -PevotorAppUuid=UUID_НОВОГО_ПРИЛОЖЕНИЯ_ЭВОТОРА
```

Для нового пакета используйте ключ `lemuria-evotor-replacement-signing` из
тестового проекта с alias `lemuria-cashier` и типом PKCS12. Gradle проверяет
сертификат до подписания. Проверяйте итоговый APK командой
`apksigner verify --min-sdk-version 23 --print-certs`, затем сверяйте UUID и ID
пакета с карточкой в кабинете.

Сборка подключается только к тестовому API. У нового пакета собственные настройки
и журнал. Для проверки используйте тестовый токен, сопоставьте позиции с
карточками Эвотора и убедитесь, что на устройстве нет незавершённого расчёта.
